# Aayush Yadav — AI & Data Science Portfolio

Personal portfolio showcasing AI/ML projects, production systems, technical notes, live Streamlit demos, and skills in data science and MLOps.

## Features

- Interactive project showcase with detail modals
- Live demo links (Playground section)
- Technical notes (production + personal deep-dives) with filters
- Responsive layout (desktop, tablet, mobile)
- Deployed via GitHub Pages

## Tech Stack

- HTML5, CSS3, Tailwind CSS, JavaScript
- Python ecosystem: Streamlit, FastAPI, scikit-learn, TensorFlow, PyTorch
- Deployment: GitHub Pages, Docker, Render, Heroku, Vercel (demos)

## Live Site

[https://03ady.github.io/Aayush-Portfolio/](https://03ady.github.io/Aayush-Portfolio/)

## Local Setup

```bash
git clone https://github.com/03ADY/Aayush-Portfolio.git
cd Aayush-Portfolio
```

Open `index.html` in your browser, or use a local server (e.g. Live Server in VS Code).
